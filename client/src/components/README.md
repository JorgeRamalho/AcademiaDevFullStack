# `client/src/components/` — componentes reutilizáveis

| Arquivo | Função |
|---------|--------|
| `Layout.tsx` | Shell da aplicação: cabeçalho, navegação principal, `<main>`, rodapé. |
| `ui.tsx` | Primitivos de UI (botões, cartões, badges, inputs compostos). |
| `HeroForge.tsx` | Hero ilustrado da página inicial. |
| `Illustration.tsx` | SVGs e ilustrações temáticas reutilizáveis. |
| `AnswerForm.tsx` | Formulário de resposta de exercícios (tipos variados). |

Componentes aqui não devem registrar rotas; páginas em `pages/` orquestram dados e navegação.
