# `server/data/` — persistência local

| Item | Função |
|------|--------|
| `.gitkeep` | Mantém a pasta no Git sem versionar o banco. |
| `academia-devfullstack.db` | Arquivo SQLite criado em runtime (ignorado pelo `.gitignore`). |

O caminho padrão é `server/data/academia-devfullstack.db` (`ACADEMIA_DEVFULLSTACK_DB` no `.env`).
